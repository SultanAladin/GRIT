Interactive Tooltip Button Preview

Implementation Details

  • Button scales on hover (currently 1.15x with ease-in-out)
  • Tooltip appears after 200ms hover delay
  • Tooltip placement: At Cursor or Widget Edge
  • Widget Edge directions: Right, Left, Above, Below
  • At Cursor: Follows mouse with offset (default 15px)
  • Widget Edge: Spawns at specified edge + offset
  • Slide animation: Optional (disabled by default in C++)
  • Slide in HTML: CSS transition (opacity + transform)
  • Slide in UE5: Requires UWidgetAnimation or manual interpolation
  • Color theme: #191919 (RGB 0.098958)
  • Font: 15pt, Light weight, White text
  • Border radius: 10px rounded corners
// C++ Usage Example:
InteractButton->HoverScale = 1.15f;
InteractButton->ScaleDuration = 0.2f;
InteractButton->ScaleType = EScaleCurve::EaseInOut;
InteractButton->InteractTooltipText = FText::FromString("Your info");
InteractButton->TooltipWidgetClass = WBP_InfoTooltip;
InteractButton->TooltipPlacement = ETooltipPlacement::WidgetEdge;
InteractButton->TooltipDirection = ETooltipDirection::Right;
InteractButton->TooltipOffset = FVector2D(20.0f, 0.0f);
InteractButton->bEnableSlideAnimation = false; // Optional
