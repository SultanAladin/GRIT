================================================================================
                              NAMING CONVENTION
================================================================================

Prefix indicates axis/quantity:
  Fx_  = Longitudinal force
  Fy_  = Lateral force
  Vx_  = Longitudinal velocity
  Vy_  = Lateral velocity

Suffix indicates condition:
  _DeadbandEntry    = Velocity within Karnopp dead-band (re-entry condition)
  _Counteracted     = Force can be counteracted by static friction
  _StaticEntry      = Combined condition for static regime entry
  _Breakaway        = Force exceeds static friction limit
  _StaticLock       = Currently in static friction regime
