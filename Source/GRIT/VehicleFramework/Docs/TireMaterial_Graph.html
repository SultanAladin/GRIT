// Tire deformation WPO — local space in, local-space offset out.
// The material's TransformPosition (W→L) feeds LocalPos.
// The material's TransformVector (L→W) converts our output back.

float3 P = LocalPos;
float3 Offset = float3(0, 0, 0);

// Early out if deformation is disabled
if (DeformEnabled < 0.5)
    return Offset;

// ---- Radial position in the XZ cross-section (Y = axial / width axis) ----
float R = length(float2(P.x, P.z));

// Rigid zone: bead-lock + inner rim don't deform
float RigidRadius = InnerRadiusCm + BeadLockPaddingCm;

// Radial mask: 0 at rigid zone, 1 at tread surface
float RadialMask = smoothstep(RigidRadius, OuterRadiusCm, R);

// Width mask: fade deformation near sidewall edges
float WidthMask = 1.0 - smoothstep(HalfWidthCm * 0.7, HalfWidthCm, abs(P.y));

// ---- Counter-rotate: find angle relative to ground contact ----
// The wheel spins; RotationAngleRad tracks cumulative spin.
// Subtract it so the contact patch stays fixed at the bottom.
float Theta = atan2(P.z, P.x) - RotationAngleRad;

// Wrap to [-PI, PI]
Theta = Theta - 6.28318530718 * floor((Theta + 3.14159265359) / 6.28318530718);

// ---- Contact patch mask ----
// PatchHalfAngleRad defines half-width of the contact zone in radians.
// Contact is at Theta ≈ -PI/2 (bottom of wheel, -Z in local space).
float AngleFromGround = abs(Theta + 1.57079632679);  // distance from -PI/2
float ContactMask = 1.0 - smoothstep(PatchHalfAngleRad * 0.6, PatchHalfAngleRad, AngleFromGround);
ContactMask *= ContactAlpha;  // zero when wheel is airborne

// ---- Flatten: push tread vertices inward at contact patch ----
// Direction is radially inward (toward axle center in XZ plane)
float2 RadialDir = (R > 0.001) ? float2(P.x, P.z) / R : float2(0, -1);
float FlattenWeight = ContactMask * RadialMask * WidthMask;
Offset.x -= RadialDir.x * FlattenAmountCm * FlattenWeight;
Offset.z -= RadialDir.y * FlattenAmountCm * FlattenWeight;

// ---- Bulge: push sidewall outward (Y axis) near contact patch ----
// When the tire flattens at the bottom, rubber bulges outward axially.
float SidewallMask = smoothstep(HalfWidthCm * 0.4, HalfWidthCm, abs(P.y));
float BulgeWeight = ContactMask * RadialMask * SidewallMask;
Offset.y += sign(P.y) * BulgeAmountCm * BulgeWeight;

// ---- Pressure effect: under-inflation bulges sidewall uniformly ----
float PressureBulge = saturate(1.0 - PressureRatio) * 0.5;
Offset.y += sign(P.y) * PressureBulge * SidewallMask * RadialMask;

// ---- Wear: worn tread is slightly thinner radially ----
float WearShrink = WearAlpha * 0.3;  // up to 0.3 cm inward at full wear
Offset.x -= RadialDir.x * WearShrink * RadialMask * WidthMask;
Offset.z -= RadialDir.y * WearShrink * RadialMask * WidthMask;

// ---- Suspension displacement: whole tire shifts along Z ----
Offset.z += SuspensionDispCm;

return Offset;

Step-by-Step Wiring Instructions

Step 1: Create the Material

Content Browser → right-click → Material. Name it M_TireDeform. Double-click to open.

In Material Details:

  • Material Domain: Surface
  • Blend Mode: Opaque
  • Shading Model: Default Lit
  • Used with Skeletal Mesh: check if tire is part of skeletal mesh, otherwise leave off
  • Used with Static Meshes: check if tire is a static mesh component

Step 2: Add the 14 Scalar Parameter nodes

For each parameter in the table above: right-click the graph → search "ScalarParameter" → place it → set its Parameter Name to the exact string from the "C++ FName" column (e.g. Tire_Deform_Enabled). Leave default values at 0 except:

  • Tire_Deform_Enabled → default 1.0
  • Tire_OuterRadiusCm → default 35.0
  • Tire_InnerRadiusCm → default 20.0
  • Tire_HalfWidthCm → default 12.0
  • Tire_BeadLockPaddingCm → default 3.0
  • Tire_PressureRatio → default 1.0
  • Tire_LoadRatio → default 1.0

These defaults make the tire look normal when C++ hasn't written values yet (e.g. in the material preview viewport).

Step 3: Absolute World Position

Right-click → search "WorldPosition" → add Absolute World Position node.

Step 4: Transform Position (World → Local)

Right-click → search "TransformPosition" → add the Transform Position node.

  • Set Source: World
  • Set Destination: Local
  • Wire the output of Absolute World Position into its input.

Step 5: Custom Node

Right-click → search "Custom" → add a Custom expression node.

  • In the Details panel, set Output Type to CMOT Float 3
  • Set Description to TireDeformWPO
  • Click the "+" button next to Inputs 15 times to add 15 inputs
  • Rename them in order (see table above): LocalPos, DeformEnabled, OuterRadiusCm, ... through SuspensionDispCm
  • For LocalPos: set Input Type to Float 3
  • For all others: Input Type stays Float 1 (default)
  • Paste the HLSL code from the plain-text box above into the Code field

  • Set Destination: World
  • Wire the Custom node's output into this node's input.

Step 8: Connect to Material Result

Wire the TransformVector output into the World Position Offset pin on the Material Result node.

Step 9: Apply and Test

Apply the material. Create a Material Instance Dynamic in C++ or assign the material to the tire mesh. VehicleSolver will create the MID and push parameters automatically — see VehicleSolver.cpp:6984-7003.

Common Mistakes

MistakeSymptomFix
Wrong Output Type on Custom node WPO pin shows type mismatch error Must be CMOT Float 3, not Float 1
Input names don't match C++ FNames Tire doesn't deform (values stay 0) The Custom node input names can be anything — they're local HLSL variable names. The Scalar Parameter names must match C++ exactly (case-sensitive).
Forgot TransformPosition (W→L) Deformation swims when camera moves HLSL expects local-space coords. Without the W→L transform, vertices are in world space.
Forgot TransformVector (L→W) Deformation direction is wrong / rotates with view WPO expects a world-space offset. Our HLSL outputs local-space, so we must convert back.
Using TransformPosition instead of TransformVector for Step 7 Offset has wrong origin (position vs direction) Step 4 uses TransformPosition (converts a point). Step 7 uses TransformVector (converts a direction/offset).
Missing SuspensionDispCm input HLSL compile error: "use of undeclared identifier 'SuspensionDispCm'" Add the 15th input. The original ChatGPT version omitted it.
LocalPos input type set to Float 1 HLSL compile error on float3 P = LocalPos LocalPos must be Float 3 in the Custom node input type dropdown.
